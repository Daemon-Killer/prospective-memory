# v1 notes

## Why a server at all?

Capture is on the **phone**. Pull is on the **PC** (Grok). They need one SQLite file. The smallest honest bridge is a tiny authenticated HTTP API on the PC.

## Reachability

| Situation | URL to put in the Android app |
|-----------|-------------------------------|
| Home Wi‑Fi | `http://192.168.x.x:8790` (`ipconfig`) |
| Away from home | Tailscale IP, or `cloudflared tunnel --url http://localhost:8790` |

v1 does **not** include a hosted Railway/Vercel backend. Add that only if LAN+tunnel is too annoying.

## Token

`uv run pmem token` writes `data/token.txt` if missing. Android header: `X-PMEM-TOKEN`.

## Inference

No LLM key. Regex heuristics (dahi → grocery, bill → bills). MCP can still rewrite later.
